# Udemy Data Analytics Project (Learning Recreation)

## Overview
This project explores Udemy course data to analyze course performance, pricing, subscriber trends, and revenue generation across multiple subjects.

The analysis focuses on identifying high-performing categories and areas where improvements could help increase revenue.

## Tools & Technologies
- Microsoft Excel (Power Query)
- Microsoft SQL Server
- Power BI
- Python (Jupyter Notebook)

## Project Workflow
1. Data cleaning and preprocessing in Excel
2. SQL-based analysis for insights and revenue calculations
3. Visualization and reporting
4. Documentation in Medium-style report format

## Key Insights
- Web Development courses generate the highest total revenue
- Most subscribers are enrolled in All Levels and Beginner courses
- Expert-level courses are limited but present growth opportunities
- Revenue peaked between 2014–2015 before declining
